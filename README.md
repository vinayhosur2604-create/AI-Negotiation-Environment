# AI Negotiation Environment

## 📌 Description
This project simulates a negotiation between a buyer and seller using a custom reinforcement learning environment.

## ⚙️ How it Works
- The system defines a state (buyer budget, seller price, current offer)
- The agent takes actions (increase, decrease, accept, reject)
- Rewards are given based on decision quality

## 🚀 Features
- Dynamic negotiation scenarios
- Intelligent decision-making
- Real-world application

## 🛠️ Tech Used
- Python

## ▶️ How to Run
1. Install Python
2. Run the file:
   python negotiation.py

## 🎯 Goal
To demonstrate how AI can model human-like negotiation behavior using reinforcement learning concepts.
